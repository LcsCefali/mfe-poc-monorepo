# Primeiros passos para adicionar um novo Mini-App

- Crie o projeto dentro da pasta /apps/*
- Certifique que a versão do `react-native` e `react` são compatíveis entre os projetos.
- Rode o comando `pnpm dlx @callstack/repack-init`
- **Importante:** Selecione a opção de `RsPack` para o bundler ao invés do Webpack tradicional
- Após a execução, será criado um arquivo `rspack.config.mjs`
